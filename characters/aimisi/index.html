背景故事
幼年 · 拉海洛冰原

【官方 · 3.1 主线】爱弥斯的父母是磁暴研究员。一次考察中遭遇虚质磁暴，两人被吞噬；受虚质影响，父母在她记忆里的痕迹逐渐消褪——面孔、声音乃至名字都只剩轮廓。她试图拼回正在流失的记忆。【同人共识】「笔记与录音」等具体物件多为剧情演绎归纳。【官方】说明：角色档案公开短文「长航的星辉」未逐字收录幼年段，硬文本以 3.1 主线 / 游戏内剧情为准（萌百·百科交叉核对一致）。

渐湖 · 与漂泊者相遇

【官方 · 3.1 主线】为找回记忆，她独自前往渐湖——自己与父母曾经生活的小屋所在。失足坠入湖中，被当时的漂泊者救出；漂泊者在拉海洛停留期间与她同住小屋、帮她走出阴霾。她将漂泊者视为家人，并由此萌生成为英雄 / 救世主的梦想。【同人共识】「第一个让她感到被在乎」等情感措辞为剧情归纳，非档案公开原文。

星炬学院 · 拉贝尔学部

【官方】长大后她进入星炬学院拉贝尔学部，成为隧者适格者；官方简介称其「在星海轻歌的电子幽灵」，性格活泼俏皮，享受校园生活并乐于分享快乐。【官方 · 剧情】适格训练中同步率拔尖、成绩优异；以「飞行雪绒」为化名活跃于网络，成为校园人气神秘歌手（面容不为人知）。【同人共识 / 企划外延】兴趣广泛串门社团、多平台角色官号等属社群归纳与宣发外延，勿写成索拉里斯物理法则。

隧门事件 · 牺牲

【官方】拉海洛深处隧门被破坏，鸣式阿列夫试图吞噬城市。本为驾驶课，模拟舱外却是真灾难。她突破神经同步安全阈值，与隧者超频共鸣：隧者被短暂唤醒，鸣式被封印回隧门之后。代价是肉体在超频中被撕碎，学生档案变成数据错误。学院登记其为「失踪的适格者」，材料上报洛瑟菈校长。

电子幽灵 · 现状

【官方】她依附隧者炉芯残余能量，以电子幽灵形态留存——自由漂浮、可进入数据系统内部，多数人看不见她。【本站原创】飞行雪绒官号停更后，她仍在调频 9072 的深夜广播里轻歌。【官方】后从隧门之后重返拉海洛；隧者离前赠予部分力量——现可显化隧者兵装、切换机兵形态参战。

展开 · 适格者与「人的本质」
【官方】适格者从索拉里斯各地选拔，借助外置装置与巨型机体「隧者」建立意识连接。星炬学院设拉贝尔学部专事培养。【官方 · 角色故事】同学曾讨论「人的本质」：爱、记忆、自我、信仰……爱弥斯后来只能理解为——人的本质是频率。躯体已毁却仍存在，她自问是否因与隧者共鸣而改变了存在性质。

【官方】核心履历对齐：档案公开「长航的星辉——爱弥斯」、游戏内鉴定报告，以及 3.1 主线（父母 / 虚质磁暴 / 渐湖小屋 / 家人线）。档案公开短文未写幼年，不代表幼年非官方。【本站原创】调频 9072、站内夜电台频道为本站演绎，不改写官方宇宙规则。

性格特征
  • 开朗阳光：【官方】走到哪都带着笑声；成了电子幽灵也照样在走廊飘来飘去，当隐形观众。
  • 活泼俏皮：【官方】爱搞怪、起昵称；给机兵写自运转逻辑时还配上带表情包的使用说明。
  • 温柔共情：【同人共识】对他人情绪敏感。有人难过时不讲大道理，只在旁边默默飘着，偶尔哼歌。
  • 为他人着想：【官方】目标规划课上写下「拯救世界」，全班笑过——后来她真的做了。
  • 「要轻松快乐地活着」：【官方 · 剧情】漂泊者临走前的嘱托 / 她自己的理想表述（角色故事有「轻松快乐地生活」）；背后藏着只有自己知道的沉重。
  • 英雄执念：【官方】战斗宣言「我会消灭，意图毁灭的恶」；希望让重要的人为她骄傲。
