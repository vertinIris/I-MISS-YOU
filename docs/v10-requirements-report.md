## 1. 内容分层架构方案

### 1.1 层级模型（三层）

- **L0 · 首页入口卡**：每个角色一张入口卡（头像 / 一句话定位 / 属性标签 /「深入了解 →」）。首页保持简洁，**不展开**角色详情。
- **L1 · 角色专区（独立深层级）**：点击入口卡进入。专区顶部为角色名 + 一句话定位 + 属性速览条 + 6 个模块入口。
- **L2 · 模块详情**：每个模块点击展开（折叠面板）或进入子页，承载具体正文。

### 1.2 交互模式（供实现对话选型）

| 方案 | 形态 | 优点 | 缺点 | 适用层 |
|------|------|------|------|--------|
| **A 折叠面板** | 单页内模块点击就地展开/收起 | 无路由、实现简单、SEO 友好 | DOM 较长 | L1→L2 |
| **B 子页** | `characters/aimisi/...` 独立 HTML | 首页与专区彻底分离，最简洁 | 文件多、需导航 | L0→L1 |
| **C Hash 路由浮层** | 点击角色卡弹出全屏专区浮层 | 沉浸、首页零污染 | 需 JS 状态管理 | L0→L1 |

**推荐组合**：L0→L1 用 **B 或 C**（专区与首页分离，保证首页简洁）；L1→L2 用 **A**（折叠面板，单页内可读性好、移动端友好）。

### 1.3 导航层级

- 顶部导航新增「角色」入口，锚点/下拉至各角色专区。
- 每个专区顶部面包屑：`首页 / 角色 / 爱弥斯`。
- 专区内部左侧/顶部模块导航，支持锚点跳转。

### 1.4 可读性规范

- 正文：glass 卡片容器，行高 1.7–1.8，最大正文宽度约 70ch。
- 时间线：竖向轨道（复用现有 `.archive-timeline` 样式类）。
- 移动端：折叠面板默认收起，点击展开；专区页单列流式。

### 1.5 内容清单与一致性

- **爱弥斯**：已完成，作为对齐模板（6 模块：背景 / 性格 / 能力 / 关系 / 音乐 / 语录）。
- **达妮娅**：已完成（优先）。模块 E 命名为「演绎与表达」（角色 PV / 音感仪 / 设计核心），契合其无音乐副业但重「伪装艺术」的设定；其余模块一致。
- **西格莉卡 / 漂泊者**：待编写，沿用相同 6 模块骨架；模块 E 可按角色微调命名（如漂泊者用「旅程记录」）。
- 现有首页内容（Profile / 动态 / 日志 / 社区）保持不变；角色专区为**新增**深层分区，不破坏首页简洁性。

## 2. 视觉色彩体系（已落地令牌）

### 2.1 方向（用户明确要求）

- **核心三色**：粉 `#F4729B` · 白 `#F0F4FF` · 浅蓝 `#6B8AFF` / `#A8D8FF`
- **辅助点缀**：橙金 `#E8A23D`（`--c-accent`）——仅用于高亮 / 焦点环 / 少量强调，**不作主色**
- **金色 `#FFD700`**：降级为未使用令牌，**不作为重点色**
- **紫色**：仅保留为达妮娅角色着色（柔薰衣草 `#B89CD9`），不进入品牌主色
- **液态玻璃**：保留（`1px` 内折射边 + 内阴影，`blur 24px saturate 140%`）

### 2.2 关键令牌表（实现对话直接引用）

```css
--c-primary: #F4729B;          /* 主色粉 */
--c-primary-strong: #E84C7E;
--c-primary-soft: #FFB6D9;
--c-core-white: #F0F4FF;       /* 核心白 */
--c-core-blue: #6B8AFF;        /* 核心浅蓝 */
--c-core-blue-light: #A8D8FF;
--c-accent: #E8A23D;           /* 橙金·辅助点缀 */
--c-accent-strong: #D08A2C;
--c-accent-soft: #F4C277;
--gradient-dynamic: linear-gradient(135deg, #F4729B, #FFB6D9, #F0F4FF, #A8D8FF, #6B8AFF, #A8D8FF);
--gradient-brand: linear-gradient(135deg, #F4729B 0%, #A8D8FF 100%);
/* 角色专属着色（次要用，非品牌主色） */
--aimisi-pink: #F4729B;        /* 爱弥斯=粉 */
--denia-lavender: #B89CD9;     /* 达妮娅=柔薰衣草 */
--sigrica-green: #4EC89A;      /* 西格莉卡=青绿 */
--drifter-blue: #6B8AFF;       /* 漂泊者=浅蓝/电蓝 */
```

### 2.3 应用规则

- 品牌主色一律走 **粉 / 白 / 浅蓝**；主 CTA 用 `--gradient-brand` 或 `--gradient-dynamic`。
- `--c-accent`（橙金）只用于：focus 环、active 态、关键信息高亮（如「调频 9072」标签），**用量克制**。
- 角色专区背景：中性锌灰骨架 + 该角色着色（见上表），避免全站共用同一条渐变导致的均质化。
