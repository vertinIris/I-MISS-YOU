## L1 · 模块 A — 背景故事（时间线）

**1. 幼年 · 拉海洛冰原**
爱弥斯的父母是磁暴研究员。一次野外考察中磁暴突然爆发，两人被吞没。受虚质辐射影响，父母在她记忆里的痕迹逐渐消褪——面孔模糊了，声音淡了，到最后连名字都只剩轮廓。她一个人守着冰原上的小屋，反复翻找父母留下的笔记和录音，想把正在流失的记忆拼回来。

**2. 渐湖 · 与漂泊者相遇**
为了找回记忆，她独自前往冰原上的渐湖——父母曾经工作生活的地方。冰面碎裂，她坠入湖中，是漂泊者伸手把她拉了上来。漂泊者在拉海洛停留了一段时间，陪她住在小屋里，帮她慢慢走出阴霾。对爱弥斯来说，漂泊者不只是救命恩人，更是父母消失后第一个让她感到「被在乎」的人。她把漂泊者当成家人。

**3. 星炬学院 · 拉贝尔学部**
长大后的爱弥斯进入星炬学院，就读于专门培养隧者适格者的拉贝尔学部。她的同步率在同期学生中最高，成绩拔尖，和谁都处得来。她还偷偷注册了一个叫「飞行雪绒」的网络账号，翻唱、原创、深夜广播，很快成了校园里人人讨论的神秘歌手——没人知道飞行雪绒长什么样，更没人想到她就是那个总在社团之间串门帮忙的开朗女孩。

**4. 隧门事件 · 牺牲**
拉海洛深处的隧门被破坏，另一侧的鸣式阿列夫试图向上吞噬整座城市。那本是一次驾驶课，模拟舱外却是真的灾难。爱弥斯做了她在目标规划课上写下的那件事——拯救世界。她突破神经同步安全阈值，和隧者完成超频共鸣。隧者被唤醒了一个瞬间，鸣式被封印回隧门之后。代价是她自己：身体在超频中被撕碎，学生档案变成一片数据错误。学院把她登记为「失踪的适格者」，材料上报给了洛瑟菈校长。

**5. 电子幽灵 · 至今**
她没有真正消失。爱弥斯依附在隧者炉芯的残余能量上，以电子幽灵的形态留在星炬学院。她能自由漂浮、进入数据系统内部，甚至飘到录音室上方听人弹琴，却再也没法像从前那样站在舞台上。飞行雪绒的官号停更了，学院走廊里三十七个人和她擦肩，没有一个人转头。后来她从隧门之后重返拉海洛，隧者在离开前赠给她一部分力量——现在她能显化隧者兵装、变身机兵形态参战，也能在频率 9072 的深夜广播里唱几首歌。

## L1 · 模块 B — 性格特征

- **开朗阳光**：走到哪都带着笑声，习惯把气氛搞热。成了电子幽灵也照样在走廊里飘来飘去，给社团活动当隐形观众。
- **活泼俏皮**：喜欢搞怪、爱起昵称，给机兵写完自运转逻辑还专门配了带表情包的使用说明。
- **温柔共情**：对别人的情绪很敏感。有人难过时她不讲大道理，只在旁边默默飘着，偶尔哼两句歌。
- **为他人着想**：梦想是拯救世界。当年在目标规划课上写下这句话，全班都笑了，后来她真的做了。
- **「要轻松快乐地活着」**：这是她的口头禅，也是她经常去不同社团帮忙、体验各种爱好的理由。这句话背后藏着的，是只有她自己知道的沉重。

## L1 · 模块 C — 能力体系

- **共鸣力**：长航的星辉。使用共鸣能力时显化隧者兵装并与之融合，变身为机兵形态，化作星辉在夜色中飞行。
- **声痕**：胸口。拉贝尔曲线呈稳定上升态，判定为自然型共鸣者；成为电子幽灵后声痕发生变化，状态不算稳定。
- **双形态**：爱弥斯形态（迅刀近战）/ 机兵形态（隧者兵装融合，双翼可飞行），通过「构型切换」自由转换。
- **共鸣模态**：震谐（对单强化，配合震谐轨迹叠加伤害）/ 聚爆（对群强化，引爆聚爆效应）。
- **核心技能**：构型切换、光翼共奏（降临/登台）、星辉破界而来（过载→终结）、流光突进（飞行移动）。
- **武器**：永远的启明星（逐星）。「你在寂静的星海中飞行，星屑在身侧崩解，时间在身后消亡。」
- **特殊**：电子幽灵形态可进入数据系统内部、自由漂浮，无法干涉生者行为，但能观测一切。

## L1 · 模块 D — 人物关系

- **漂泊者**：家人。幼年在渐湖救了她，陪她在拉海洛生活了一段时间，是超越普通亲情的深刻羁绊。
- **琳奈**：星炬学院同学。曾在爱弥斯生日时赠送小型隧者手办，期望与她共赴「真正的星空」。
- **西格莉卡**：星炬学院同学，罗伊族出身，与达妮娅是挚友，在学院中担任助教。
- **千咲**：星炬学院同学（朽叶千咲），同期适格者之一。
- **洛瑟菈**：星炬学院校长。爱弥斯失踪后，损毁的学生档案被上报至她处。「那孩子明明看起来那么开朗……」
- **达妮娅**：星炬学院学生、残星会实验体，与西格莉卡互称昵称（娅娅/西西），是学院里少数知晓彼此秘密的人。
