### [R-071] 短篇故事 · 渐湖水面下的那只手

内容：
罗伊冰原的冷，是会渗进骨头缝的那种冷。但渐湖不一样——湖面结着薄冰，水下却有地热在缓慢地呼吸，像是这片冻土偷偷藏起来的一口暖气。

女漂泊者赶到的时候，冰面已经裂开了一道缝。一只小小的手从水里伸出来，指尖冻得发青，在半空里抓了两下，又往下沉。她什么都没想，把手臂探进刺骨的水里，把那个小小的、轻得像片羽毛一样的身体捞了上来。

那是个罗伊人的孩子，银灰色的头发贴在脸颊上，睫毛挂着冰碴。孩子睁不开眼，只本能地攥住了漂泊者的衣角。漂泊者把她裹进自己还带着天外寒意的斗篷里，用掌心一遍遍搓着她冻僵的手脚，直到那双手重新有了温度，开始小幅度地发抖——那是活过来的征兆。

后来她才知道，这孩子叫爱弥斯。

很多年后爱弥斯成了「飞行雪绒」，成了别人眼里笔锋明亮的少女，可漂泊者每次路过渐湖，都会下意识看一眼那道裂痕。她从没跟任何人提过自己那一刻的害怕：怕慢了一步，怕手够不到，怕怀里这个轻飘飘的重量从此就沉进湖底。她只是把害怕咽下去，换成更紧的拥抱。

她没说「我会保护你」。她说的是：「醒了就先喝口热水。」

### [R-072] 场景描写 · 把作业本摊在膝头的光

内容：
罗伊人的夜晚很长。冰原上的星比别处密，落进窗子里，像撒了一地碎玻璃。

漂泊者盘腿坐在渐湖边的小屋里，把爱弥斯的作业本摊在自己膝头。火炉噼啪响着，把孩子冻红的鼻尖烘出一点暖色。爱弥斯趴在她腿边，下巴搁在桌沿上，握笔的姿势歪歪扭扭，写两个字就要抬头偷看她一眼，确认这个人还在。

「这一题，先算你的频率余量。」漂泊者拿木炭在纸边画了道横线，「罗伊人的作业也要讲守恒，你昨天把数字抄反了。」

「可是好难。」爱弥斯把脸埋进臂弯，「外头的人都说我能拯救世界，怎么连除法都救不了。」

漂泊者顿了顿，没笑出声。她伸手把那页纸翻过去，重新写了一个更慢的例题，一个步骤一个步骤地推。「拯救世界不急。今晚先把这一页写完。」

她教得很慢，慢到几乎不像那个在冰原上独行、说话总留三分的御者。木炭屑落在她银发上，她也没察觉。爱弥斯写着写着睡着了，笔尖在纸上拖出长长一道。漂泊者没有叫醒她，只是把笔轻轻抽走，用指节蹭了蹭孩子额头——一个还没变成「刮鼻子」的、更笨拙的疼爱。

那盏灯亮到很晚。窗外风声很大，屋里只有炭火和呼吸。

### [R-078] 考据分析 · 「频率流失」在 3.1 的加重与叙事重量

内容：
【考据向 · 基于官方基线 + 社区读解】

**已知基线**
- 女漂泊者的力量与「频率」相关，拉海洛 quest 中其频率流失在 3.1 章节加重。
- 流失表现于身体与精神消耗外显，她在对外互动中仍维持克制。

**读解一：流失是「人」的证词**
官方设定强调她「本质是人」。频率流失的加重，恰是最有力的反证破除——她不是无懈可击的神降，是会被消耗、会疲惫的同类。这解释了她为何在无人处停下、把脸埋进围巾。

**读解二：流失与「倒置」的因果**
正因为她在 3.1 越来越撑不住，关系才从「家长—孩子」倒置为「被保护—保护」。爱弥斯后期反向刮她鼻子、说「别难过」，不是突然长大，而是终于有机会把当年渐湖边被接住的那只手，递回来。

**读解三：3.1 是情感密度峰值**
流失加重 = 温柔更显珍贵。她越虚弱，那些「不说破的保护」越重。建议考据贴配时间轴：3.0 初遇教养 → 3.1 流失峰值 + 倒置发生 → 结尾远航星。

### [R-121] 考据分析 · 「家长→孩子」倒置：拉海洛最痛也最暖的弧光

内容：
【考据向 · 官方基线 + 社区读解】

**官方基线**
- 女漂泊者教幼年爱弥斯写作业、双人游戏、一招一式，关系由家长→孩子。
- 后期关系倒置为保护：爱弥斯成为保护方，漂泊者为被保护方。
- 刮鼻子由长辈对晚辈，终由爱弥斯反向使用，说「别难过」。

**读解一：倒置是「被接住」的闭环**
渐湖边那只冻红的手被接住，是弧光起点；3.1 漂泊者撑不住、爱弥斯回护，是弧光落点。中间所有「教」，都是为了这一刻——让被救的人，有能力反过来救。

**读解二：刮鼻子的语义翻转**
同一动作，施受反转，含义从「我宠你」翻成「我怕你出事」。动作未变，权力关系松了。这是叙事最克制的告白：爱弥斯没说「我爱你」，只说「别难过」，用当年被给的温柔，原样递回。

**读解三：痛在「不得不」，暖在「来得及」**
倒置之痛，是家长终于承认自己也会塌；暖，是塌的时候，有人接。拉海洛把「成长」写成双向的——不是孩子长大离开，是两人终于平视。

［考据边界：读解为社区分析，非官方定论。］
