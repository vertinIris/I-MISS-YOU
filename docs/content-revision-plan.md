# 飞行雪绒 · 文字修改方案与人物故事创作手册（v10 内容层）

> **定位**：本文件是上一轮《内容一致性审查 / 架构评估 / 文案修正报告》的**落地版**。报告只给结论，本手册给「怎么改、改成什么、为什么、人设怎么守」。
> **范围**：动态时间线 Posts 1–7 · 角色日志 diary 1–6 · 种子评论（挂在 posts/diary 下）· 社区投稿 seed_1–11 · 头像/配色令牌。

> **说明**：本手册**仅文字方案，不含任何代码/画布改动**。所有修改项标注了精确文件与行号，供后续执行定位。

## 〇、使用方式

- **第一篇「修改清单」**：逐条对应报告 C-01~C-09 + 视觉令牌，每条含「原文 / 问题 / 原因 / 具体方案」。
- **第二篇「人物篇」**：五个角色（爱弥斯、达妮娅、西格莉卡、女漂泊者、琳奈）的完整背景故事，供写作时取用。
- **第三篇「细节篇」**：人设贴合度红线与每角色的语言/思维/行为/互动规范。
- **第四篇「剧情篇 · 对话篇」**：把修改清单的替换文本放回原文语境，给出可直接粘贴的完整改写；附角色对话语气对照表。
- **第五篇「疏漏补充」**：缺失的基线文档草案 + 时间线/口径一致性修复 + 视觉令牌对照表 + 待建清单。

| 位置 | `index.html:1107`（Post 6）、`index.html:1380 / 1382`（Diary 6）、`js/main.js:2204`（seed_9《纸飞机》）、`js/main.js:2214`（seed_11 琳奈转述「渐湖的冰面下面有鱼」属他人视角，可保留） |
| 原文 | 1107：「妈妈哼歌时候的调子，爸爸把围巾绕两圈才打结的习惯。这些存在身体里。」<br>1380：「爸爸每隔两天就去凿冰钓鱼。妈妈在屋里织东西……绕两圈才打结的那种。」<br>1382：「妈妈哼歌的调子，爸爸围巾绕两圈的习惯，渐湖冰面下面鱼游过去时候的震动。」<br>2204（seed_9）：「小时候在渐湖，爸爸教我折纸飞机。他折的飞机总是飞得又直又远……他说没关系，打转的飞机也有打转的飞法。」 |
| 问题 | 与分层文档「记忆消褪——面孔模糊、声音淡了、连名字只剩轮廓」直接冲突。当前写出**完整温暖的生活细节**（围巾打结手法、凿冰频率、织围巾、教折纸飞机对话），弱化了官方「记忆正在流失」的残缺痛感。 |
| 原因 | 爱弥斯的核心情感线之一是「想把正在流失的记忆拼回来」，记忆必须「残缺但有温度」，而非「完好」。 |
| 具体方案 | 将「记得细节」改写为「记得温度，记不清细节」——保留温暖收尾「记得他们爱过我，这就够了」，但把具体画面改成「从笔记/录音里看来的」或「只剩残影」。<br>**统一替换口径**：凡写爱弥斯忆父母，只允许出现「调子的头几个音」「围巾绕两圈的轮廓」「冰面下鱼影的震动感」这类**感官残片**，不得出现可还原成完整场景的对话或动作描写。 |

**建议替换文本（以 1107 为例）**：
> 「有些东西，不需要字迹也能记住。比如妈妈哼歌时开头那几个音——后面的我早就想不起来了；比如爸爸围巾绕两圈的轮廓，其实是从他留下的笔记里看来的，他的脸我早记不清了。这些存在身体里，不在纸上。我记得他们爱过我，这就够了。」

# 第二篇 · 人物篇（人物故事创作）

> 以下为背景故事库，供后续写作「取用」。爱弥斯、达妮娅严格贴合分层文档；西格莉卡、女漂泊者为**草案**，标 ⚠️ 处为待官方核实的推断。

## 2.1 爱弥斯 / 飞行雪绒

### 一、性格特征与行为习惯
- **开朗是盔甲，不是天性**：她并非不知痛苦，而是主动把痛苦压在「要轻松快乐地活着」这句话后面。习惯在走廊飘来飘去当隐形观众、给社团帮忙、给事物起昵称、给机兵自运转逻辑配表情包使用说明——这些都是「把气氛搞热」的本能动作。
- **温柔共情，不讲道理**：旁人难过时她不劝、不说教，只默默飘在旁边，偶尔哼两句歌。
- **为他人着想到自我牺牲**：梦想是「拯救世界」，在目标规划课写下被全班笑，后来真做了。
- **小习惯**：哼歌（妈妈调子的残影）；给事物起昵称；在录音室上方听人弹琴；用数据视角观察世界（哪桌空着、哪束光好）。

### 二、核心动机与情感线索
- **表层动机**：轻松快乐地活着。
- **深层动机**：把正在流失的父母记忆拼回来（面孔模糊、声音淡了、名字只剩轮廓）；报答漂泊者（第一个让她感到「被在乎」的人，当家人）；不让任何人再经历「被留下」。
- **情感线**：对父母记忆的执念（残缺痛感）→ 对漂泊者的家人羁绊 → 对同学的温暖（琳奈手办、千咲、西格莉卡）→ 牺牲后成为电子幽灵的孤独与「被听见」的渴望（调频 9072 深夜广播）。

### 三、关键经历与成长轨迹
1. **幼年冰原**：父母是磁暴研究员，野外考察被磁暴吞没；虚质辐射使记忆在她脑中消褪。她守着小屋翻笔记和录音，想拼回记忆。
2. **渐湖相遇**：为找回记忆独赴渐湖，冰面碎裂坠湖，漂泊者伸手拉她上来；漂泊者陪住小屋一段时间，被她当家人。
3. **星炬学院 · 拉贝尔学部**：同步率同期最高，偷偷注册「飞行雪绒」账号翻唱、原创、深夜广播。
4. **隧门事件 · 牺牲**：驾驶课遇真灾难，突破神经同步安全阈值超频共鸣，唤醒隧者封印鸣式阿列夫，身体被撕碎成数据错误，登记「失踪的适格者」上报洛瑟菈校长。
5. **电子幽灵 · 至今**：依附隧者炉芯残余能量，自由漂浮、进数据系统、观测一切但无法干涉生者；后从隧门后重返拉海洛，隧者赠力，能显化兵装、机兵形态、在 9072 广播里唱歌。

### 四、人物关系网络
- **漂泊者**：家人 / 救命恩人 / 引路者。
- **琳奈**：同班，赠隧者手办，约「共赴真正星空」。
- **西格莉卡**：同学、罗伊族助教。
- **千咲**：同期适格者（朽叶千咲）。
- **洛瑟菈**：校长，「那孩子明明看起来那么开朗……」。
- **达妮娅**：互知秘密的同学（残星会实验体）。

## 2.2 达妮娅 / 娅娅

### 一、性格特征与行为习惯
- **慵懒**：任何课堂、任何讲师，都可能见她偷睡。
- **矛盾体**：无害好学生 vs 鸣式预备共鸣者；渴望被拯救，又主动拒绝救赎。
- **软心肠**：你带甜点去求她，她帮你「蒙对」方向、替你收集论文数据（数据哪来，别问）。
- **伪装艺术家**：角色 PV「人类伪装指南」的假笑致敬《DARKER THAN BLACK》基尔西；收声手势致敬 Faker；片尾「已同步」出自《银翼杀手 2049》。
- **对西格莉卡的偏执温柔**：唤「西西」，被唤「娅娅」；西西是「给她带来生命光芒的存在」。

### 二、核心动机与情感线索
- **核心矛盾**：渴望被拯救，却主动拒绝救赎。
- **情感线**：对西西的珍视（生命光芒）vs 注定消失；对漂泊者「最讨厌」的复杂——漂泊者正是「想把所有人救起来」的人，照见了自己渴望却被拒绝的救赎；最终选择「归于尽」，把所有人推到安全侧。

### 三、关键经历与成长轨迹
1. **拉海洛的孩子**：名字取自俄语「До свидания」（再见）与「С днем рождения」（生日快乐）——告别，也生日。
2. **双重身份**：表面好学生（偷睡、被甜点收买蒙对方向）；背地残星会成员兼实验体、鸣式预备共鸣者。
