# 双站纠正案（允许推翻）· 2026-11-14

## 诊断（你的直觉对）

1. **视觉**：档案环 / 世界观卡 / 讨论帖 三套都是「深色圆角卡片」→ 统一、像模板、缺场所感。  
2. **定位**：主站已有时间线·投稿·角色入口；论坛又有讨论区·档案库·世界观 → **两套半成品社区**，互相稀释。  
3. **3D / Tauri**：现有档案已是 CSS billboard 环，但透视弱、像「框里贴片」。独立壳**不能自动变精致**；Tauri = 同 WebView + 可安装窗口。真 3D 收纳在浏览器也可做，壳只是放大器。

## 纠正后的硬分工（推翻旧「两站都像论坛」）

| | **飞行雪绒** | **星炬学院** |
|---|---|---|
| 一句话 | 深夜电台·私人频道 | 学院档案处·同人广场 |
| 人称 | 爱弥斯第一人称 | 第三人称档案 / 考据 / 讨论 |
| 必有 | Web Audio、日志、电台页脚、调频彩蛋 | 3D 档案收纳、世界观考据、UGC 讨论 |
| **禁止再堆** | 全员档案环、世界观卡墙、通用论坛流 | 夜电台叙事主舞台、粉皮换色皮 |

跨站关系：**雪绒 = 听 / 感**；**学院 = 查 / 议**。入口互链保留，功能不镜像。

## 视觉方向（反统一卡片）

- **档案库**：立体「标本柜 / 展柜」——强透视、地面光池、前后景差、停悬交互（沿用 `ui-motion-3d` billboard，加深材质）。  
- **世界观**：书脊/卷宗抽屉，不是四宫格同宽卡。  
- **讨论区**：布告栏 / 邮戳信笺，不是社交 App feed 克隆。  
- **主站雪绒**：继续编辑式夜电台，禁止论坛三件套外观。

## Tauri 结论

| 问题 | 答案 |
|------|------|
| 做成独立是否就能更 3D？ | **否**。效果来自设计与实现，不来自壳。 |
| 还要不要壳？ | 可要：安装包、任务栏、少浏览器铬。建议 **Web 场所感先成立 → 再套最小 Tauri**。 |
| 3D 建议 | 档案柜优先；全站 WebGL 过重且伤阅读。 |
