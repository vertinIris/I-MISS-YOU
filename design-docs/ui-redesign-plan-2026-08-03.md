# 飞行雪绒 & 星炬学院主论坛 · UI 重设计方案

> 说明：本文档为纯设计方案，**不涉及具体代码实现**。后续开发可依据本文直接落地。
> 范围：论坛主页（`forum/index.html`）与飞行雪绒主页（`index.html`）的 UI/UX 调整；**角色独立页暂不处理**。

---

## 一、设计目标

1. 将论坛板块从「网格卡片」改为更接近社交动态流的时间线体验，提升信息浏览效率。
2. 将论坛中的信息卡片改为「抽屉式半收纳」：默认收起，悬停/点击展开完整内容，降低首屏信息密度。
3. 修复当前主页存在的颜色断层问题，使各区块色彩过渡自然连贯。
4. 增强爱弥斯主题动效：放慢节奏、加大幅度、提升视觉存在感。
5. 为「星炬学院主论坛」与「飞行雪绒沉浸站」建立两套独立配色体系，明确视觉区分。

---

## 二、当前问题诊断

基于 `forum/index.html`、`forum/forum.css` 及用户截图观察：

| 问题 | 表现 | 影响 |
|------|------|------|
| 卡片信息过载 | 社区卡片（`.stf-card`）默认展示全文 + 评论 + 操作栏，单屏只能看到 2~3 张卡片 | 首屏信息密度过高，用户难以快速扫读 |
| 论坛不像动态流 | 当前为 `auto-fill` 网格布局，帖子以等宽卡片平铺，缺少时间线叙事感 | 降低社区活跃感与沉浸感 |
| 颜色断层 | Hero 区使用粉蓝紫径向渐变叠加，但向下进入功能区/社区区时背景变为近黑，缺少过渡层 | 各 section 之间出现明显色块边界，视觉跳跃 |
| 爱弥斯动效弱 | 收纳册卡片浮动周期 5.5~6.8s，幅度仅 `-9px`；像素彩蛋飞出动效 1.25s 偏快 | 用户难以注意到这些精心设计的内容 |
| 两站配色未区分 | 论坛大量复用 `--aimisi-pink`、`--drifter-blue` 等飞行雪绒主题色，主论坛缺少自身品牌色 | 用户无法快速判断当前处于「星炬学院」还是「飞行雪绒」 |

---

## 三、设计原则

1. **信息分层优先**：永远先让用户看到「谁、什么时候、说了什么、能不能互动」，再决定展开细节。
2. **动效是信号，不是装饰**：每个动画都必须引导注意力或反馈状态；爱弥斯作为叙事主角，动效应更慢、更大、更可见。
3. **一域一色**：星炬学院主论坛使用「学院蓝金」体系，飞行雪绒站使用「粉白星光」体系，两站仅通过彩蛋入口互链。
4. **渐变连贯，而非色块拼接**：全站背景使用一条连续的深空渐变轴，各 section 通过透明度、光晕、装饰层区分，而非更换底色。

## 四、详细设计方案

### 4.1 卡片交互：抽屉式半收纳

#### 设计定义
每张帖子卡片默认处于 **半收纳（Collapsed）** 状态；当用户悬停（桌面）或点击卡片任意非按钮区域（移动端）时，进入 **展开（Expanded）** 状态。

#### 收起态（Collapsed）
只保留以下元素：
- 头像（左）+ 用户名 + 时间戳（右）
- 类型标签（轻量胶囊）
- 标题（单行截断）
- 内容预览（最多 2 行，约 60 字）
- 底部互动数据：点赞数、评论数、收藏数（纯数字，无输入框）

视觉参数建议：
- 卡片高度固定或最大高度约 `140px`
- 内容区 `mask-image: linear-gradient(to bottom, black 70%, transparent 100%)` 制造底部渐隐
- 右下角显示「展开 ↓」微按钮

#### 展开态（Expanded）
在收起态基础上展开：
- 标题取消截断
- 内容完整显示（保留换行）
- 显示完整标签行（角色 + 类型标签）
- 显示评论列表 + 评论输入框
- 操作按钮从「数字」变为可点击的「点赞 / 评论 / 收藏」按钮

#### 动效规范
- 展开：`height` 动画 350ms，`cubic-bezier(0.16, 1, 0.3, 1)`
- 内部内容 `opacity` + `translateY(8px → 0)` 错开 50ms 入场
- 悬停时仅触发一次微预览：标题轻微高亮、卡片整体 `translateY(-3px)`
- 移动端点击展开后，再次点击卡片主体收起；点击评论/点赞不触发收起

#### 状态保持
- 用户滚动离开展开卡片时，可配置为「自动收起」或「保持展开」；建议默认保持展开，避免误操作打断阅读。
- 当前筛选/排序切换时，所有卡片重置为收起态。

### 4.2 论坛主体：社交动态流

#### 布局重构
将 `#stf-community` 从 `grid` 改为 **单列时间线（Timeline Feed）**：

```
┌─────────────────────────────────────┐
│  发布框（快捷输入，常驻顶部）          │
├─────────────────────────────────────┤
│  ● 头像  用户名 · 2小时前            │
│     标题（单行）                      │
│     内容预览…                        │
│     ❤ 24  💬 7  ⭐ 3                │
├─────────────────────────────────────┤
│  ● 头像  用户名 · 5小时前            │
│     标题（单行）                      │
│     内容预览…                        │
│     ❤ 56  💬 12  ⭐ 8               │
├─────────────────────────────────────┤
│           加载更多 / 分页            │
└─────────────────────────────────────┘
```

#### 时间线视觉元素
- 在 feed 左侧设置一条垂直「星轨线」，宽度 `2px`，颜色为学院主色（星炬蓝 `#6B8AFF` 半透明）
- 每张卡片左侧对应一个「时间节点」圆点，hover 时放大并发光
- 最新帖子节点更亮，旧帖子节点渐隐，营造时间流逝感

#### 发布框（Quick Composer）
- 固定在 feed 顶部，默认只显示一行占位输入：「分享你的鸣潮同人…」
- 聚焦后展开为完整输入区（标题 + 类型 + 标签 + 内容），可直接在 feed 内发帖，减少弹窗打断
- 投稿弹窗（FAB / 投稿按钮）作为备用入口保留

#### 动态加载
- 第一页 6 条，滚动到底部显示「加载更多」按钮；后续可考虑无限滚动
- 新帖发布成功后，以动画形式插入 feed 顶部，节点圆点 pulse 一次

#### 互动数据展示
- 点赞、评论、收藏以 icon + 数字呈现
- 用户自己点赞/收藏后，icon 填充并切换为品牌强调色
- 评论按钮点击后展开评论区，不跳转新页

### 4.3 主页颜色断层修复

#### 当前问题
`forum-hero` 使用三层径向渐变：
- 左上粉 `#FF6B9D`（透明度 18%）
- 右上蓝 `#6B8AFF`（透明度 20%）
- 底部紫 `#B66BFF`（透明度 16%）

但 `forum-section--overview` 及后续 section 背景直接是 `rgba(255,255,255,.05)` 玻璃卡片 + 近黑底色，缺少从 hero 到 content 的过渡。

#### 修复方案
1. **全局背景连续化**
   - 将 `body` 或最外层容器背景改为一条从 `hero` 顶部贯穿到页脚的深空渐变：
     - 顶部：`#0F0B18`（偏紫黑）
     - 中上：`#0B0E1A`（偏蓝黑）
     - 中部：`#080A12`（纯黑蓝）
     - 底部：`#0D0B14`（微紫黑）
   - 所有 section 使用透明背景，仅通过背景光晕、边框、卡片区分层级。

2. **Hero 与功能区过渡**
   - 在 `forum-hero` 底部增加一个 `180px` 高度的「过渡雾层」：
     - `mask-image: linear-gradient(to bottom, transparent 0%, black 60%)`
     - 颜色继承 hero 底部紫光，向上渐隐
   - 功能区顶部卡片与 hero 重叠 `40px`（负 margin），形成自然的「浮层衔接」。

3. **Section 分隔器**
   - 用细线 + 微光替代色块切换：
     - 线宽 1px，颜色 `rgba(255,255,255,.06)`
     - 线的中间加一个 `40px` 宽的发光节点，颜色为当前 section 主色

4. **飞行雪绒站同步修复**
   - 当前 `index.html` 的 `pink-galaxy` / `galaxy-river` / `ult-energy-core` 已经多层叠加，但 section 之间仍可能出现断层。
   - 建议为每个 `.section` 增加微弱的顶部/底部光晕（`box-shadow: 0 -1px 40px rgba(...)`），或让背景层高度覆盖整页。

### 4.4 爱弥斯动效增强

#### 应用场景
爱弥斯主题动效主要出现在：
- 收纳册主卡（爱弥斯 featured card）
- 隐藏彩蛋入口触发后的像素形象飞出
- 论坛核心功能区「社区讨论」卡片的主次标识
- 论坛中爱弥斯相关帖子的角色色高亮

#### 增强方向：慢、大、亮、层次多

| 元素 | 当前 | 建议 |
|------|------|------|
| 收纳册浮动周期 | 6.8s | 12s |
| 浮动幅度 | `-9px` | `-16px` |
| 主卡光晕 | 静态 box-shadow | 呼吸式光晕（4s 周期，透明度 12% → 28%） |
| 主卡边框 | 3px 静态顶边 | 流动渐变边框（conic-gradient 旋转，8s 周期） |
| 像素彩蛋飞出 | 1.25s | 2.0s |
| 飞出轨迹 | 仅缩放+位移 | 增加旋转 `±8°`、尾迹粒子拖长、屏幕轻微粉闪 |
| 音符元素 | 静态 | 从像素角色身边以 2s 间隔弹出并消失 |

#### 具体动画建议
1. **收纳册主卡「星辉呼吸」**
   - 伪元素 `::before` 使用 `conic-gradient` 旋转，模拟爱弥斯的星光环绕
   - 伪元素 `::after` 使用大半径 blur 光斑，4s 呼吸周期
   - 卡片内容层保持清晰可读

2. **像素爱弥斯飞出**
   - 初始：屏幕中心下方 `translateY(40px) scale(0.7) opacity(0)`
   - 中段：停顿 `scale(1.05)`，光环从角色身后扩散
   - 结束：`translateY(-120vh) scale(0.4) rotate(-6deg) opacity(0)`，伴随 8~12 个音符粒子向上飘散
   - 总时长 2.0s，之后跳转

3. **社区讨论核心卡**
   - 增加「核心」飘带的微光闪烁（2.5s 周期）
   - hover 时飘带轻微摆动

### 4.5 配色区分：星炬学院 vs 飞行雪绒

#### 设计策略
- **飞行雪绒站**：保留现有「粉白星光」体系，代表爱弥斯的温柔、电子幽灵的梦幻。
- **星炬学院主论坛**：建立独立的「蓝金学院」体系，代表学术、秩序、星炬学院的庄严与神秘。

#### 星炬学院主论坛配色建议

新增/调整 CSS 变量：

```css
:root {
  /* 星炬学院主品牌 */
  --stf-brand: #6B8AFF;           /* 学院蓝 */
  --stf-brand-light: #A8D8FF;     /* 浅蓝星光 */
  --stf-gold: #E8C56A;            /* 学院金 */
  --stf-gold-soft: #F3E0A3;       /* 柔金 */
  --stf-bg-top: #0F0B18;          /* 顶部紫黑 */
  --stf-bg-mid: #0B0E1A;          /* 中部蓝黑 */
  --stf-bg-bottom: #080A12;       /* 底部深黑 */
  --stf-text: #F0F4FF;
  --stf-text-muted: rgba(240,244,255,.65);
}
```

#### 应用规则

| 元素 | 星炬学院主论坛 | 飞行雪绒站 |
|------|----------------|------------|
| 主按钮渐变 | 蓝 → 金 `#6B8AFF → #E8C56A` | 粉 → 紫 `#FF6B9D → #B66BFF` |
| 标题渐变 | 蓝 → 金 | 粉 → 浅蓝 → 紫 |
| 卡片顶边/强调 | 学院蓝 `#6B8AFF` | 爱弥斯粉 `#FF6B9D` |
| 悬浮光晕 | 蓝色系 | 粉色系 |
| 时间线轨道 | 学院蓝半透明 | 浅蓝/白色雪花 |
| 空状态/提示 | 学院蓝 | 粉色 |
| FAB 按钮 | 蓝金渐变 | 粉紫渐变 |

#### 角色色保留但弱化
- 达妮娅、西格莉卡、琳奈等角色色仍用于头像环、标签、角色档案卡顶边
- 但论坛整体氛围由「学院蓝金」统一，避免被爱弥斯粉主导

#### 两站互链入口
- 飞行雪绒站 → 论坛：页脚或隐藏入口，使用学院蓝金作为「出口」视觉提示
- 论坛 → 飞行雪绒：隐藏彩蛋（雪花 / 9072），触发后使用爱弥斯粉色系动效，作为「进入另一世界」的视觉暗示

## 五、信息架构与导航优化

### 5.1 论坛页面结构

```
Forum Index
├── Hero（品牌区 + 核心入口胶囊）
├── 功能区导览（3 入口：讨论 / 档案 / 世界观）
├── 核心社区（动态流 + 快捷发布框 + 筛选/排序/标签）
├── 角色档案收纳册（爱弥斯主卡 + 其余角色次卡）
├── 世界观考据（4 卡片）
└── 页脚（隐藏彩蛋入口 + 版权说明）
```

### 5.2 导航体系
- 顶部导航保留：首页 / 讨论 / 角色档案 / 世界观 / 投稿
- 增加当前位置高亮（scrollspy）
- 移动端汉堡菜单：展开后垂直排列，背景使用 forum 蓝黑半透明

### 5.3 主次层级
1. **核心层**：社区讨论（feed 区）—— 面积最大、位置最上、交互最多
2. **次核心层**：角色档案收纳册 —— 视觉上有「书架」容器包裹
3. **辅助层**：世界观考据、功能导览 —— 使用更小卡片、更低对比
4. **隐藏层**：飞行雪绒入口 —— 仅通过彩蛋触发

## 六、响应式适配策略

### 桌面端（>1024px）
- Feed 宽度 `max-width: 720px`，居中显示
- 左侧显示完整时间线轨道
- 收纳册：爱弥斯主卡横置，其余 5 张次卡 3+2 网格
- FAB 常驻右下

### 平板端（768px ~ 1024px）
- Feed 宽度 `90%`，时间线轨道缩窄为 `1px`
- 收纳册：主卡全宽横置，次卡 2 列
- 快捷发布框保持单行，聚焦后展开

### 移动端（<768px）
- Feed 全宽，左右内边距 16px
- 时间线轨道隐藏，仅保留头像作为时间标识
- 收纳册：主卡全宽，次卡单列
- 抽屉卡片点击展开，再次点击收起
- FAB 改为底部居中悬浮，避免遮挡内容
- 导航改为汉堡菜单

### 可访问性
- `prefers-reduced-motion: reduce` 下：所有浮动、呼吸、旋转动画关闭，仅保留透明度过渡
- 抽屉展开支持键盘 `Enter/Space` 触发
- 动效不闪烁、不覆盖可操作区域

## 七、实现边界与优先级

### 本次范围
- ✅ `forum/index.html`：卡片抽屉化、动态流布局、蓝金配色、爱弥斯动效增强
- ✅ `index.html`：颜色断层修复、与论坛配色区分（飞行雪绒保持粉白）
- ✅ 两站仅通过隐藏入口互链

### 不处理
- ❌ 角色独立页（`characters/*.html`）
- ❌ 后端数据迁移、Supabase 表结构调整
- ❌ 新增复杂功能（如私信、通知系统）

### 建议开发优先级
1. **P0**：论坛动态流布局 + 抽屉卡片（直接改变核心体验）
2. **P0**：星炬学院蓝金配色落地（建立独立品牌感）
3. **P1**：主页颜色断层修复（全局视觉连贯）
4. **P1**：爱弥斯动效增强（锦上添花，提升情感化体验）
5. **P2**：响应式细节打磨、reduced-motion 降级

## 八、预期效果

- 论坛首屏信息密度下降约 40%，用户扫读效率提升。
- 抽屉式交互使单条帖子获得「聚焦时刻」，评论与收藏行为更自然。
- 蓝金配色让星炬学院主论坛拥有独立视觉身份，与飞行雪绒站形成「学院 vs 个人」的叙事对照。
- 渐变过渡修复后，页面从 hero 到页脚形成一条连续、深邃的「星空学院」视觉动线。
- 爱弥斯动效从「背景装饰」升级为「可感知的角色出场」，强化情感记忆点。
